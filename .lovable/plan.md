# المرحلة الثامنة - المزايا الاحترافية والذكاء الاصطناعي المتقدم

نظراً لضخامة المرحلة (11 محور)، سأقسمها إلى **4 دفعات متتابعة** لضمان الجودة والاستقرار، ولن أنتقل من دفعة إلى التالية إلا بموافقتك.

---

## 🎯 الدفعة الأولى — QR Code + الأرشيف + البحث العالمي
**الأساسيات الوظيفية السريعة (بدون AI ثقيل).**

### 1. نظام QR Code الذكي
- توليد QR Code فريد لكل طالب يوجّه إلى `/admin/students/scan/:code`.
- إضافة QR في: كارت الطالب، صفحة البروفايل، ملف PDF، بطاقة الطباعة.
- **صفحة المسح**: مكوّن `QRScanner` باستخدام كاميرا الهاتف (`html5-qrcode`) داخل `/admin/scan`.
- صفحة سريعة `/admin/students/quick/:code` تعرض: الصورة، الاسم، الكود، الصف/المجموعة، آخر امتحان ونتيجته، متوسط الدرجات، النقاط، المستوى، الجوائز، الشارات، آخر حضور + أزرار (واتساب، رسالة، محادثة، تعديل).

### 2. أرشيف الطلاب
- إضافة عمود `archived_at` و `archived_year` لجدول `students`.
- تحديث RLS بحيث لا تظهر الطلاب المؤرشفون في القوائم الافتراضية.
- صفحة `/admin/archive`: بحث + فلترة (السنة/الصف) + إجراءات (استرجاع، نقل لسنة جديدة، نسخ، تصدير).
- إجراء جماعي "أرشفة نهاية العام" في صفحة الطلاب.

### 3. البحث العالمي (Command Palette)
- مكوّن `GlobalSearch` (Ctrl+K) في Header الأدمن.
- بحث موحّد عبر: الطلاب، الامتحانات، النتائج، الرسائل، الجوائز، الملفات، الإعلانات، التقارير.
- server function `globalSearch` يستخدم فهارس `pg_trgm` الموجودة، ويرجع نتائج مصنّفة.

## 🤖 الدفعة الثانية — المساعد الذكي + التحليلات بالـ AI

### 4. مساعد المدرس الذكي (AI Assistant Chat)
- صفحة `/admin/ai-assistant` بواجهة محادثة كاملة (AI Elements: Conversation, PromptInput, Message).
- محادثات محفوظة في قاعدة البيانات (جدول `ai_conversations` + `ai_messages`).
- Tools (Function Calling) قابلة للتنفيذ:
  - `generate_exam`, `create_review`, `create_summary`, `create_homework`
  - `send_announcement`, `send_message_to_students` (مع تأكيد قبل التنفيذ)
  - `analyze_results`, `suggest_review_topics`, `create_competition`
- كل مهمة تستخدم المزوّد المناسب من `ai_providers` (fallback موجود).

### 5. لوحة التحليلات بالـ AI
- صفحة `/admin/ai-analytics`.
- تجمع بيانات الأداء وتُرسلها لنموذج AI لإنتاج:
  - تحليل الصفوف/المجموعات/الأسئلة/الحضور/الرسائل.
  - اقتراحات ذكية (مراجعة درس، إنشاء واجب، تقسيم مجموعات).
- تعرض النتائج كـ Charts (Recharts) + بطاقات توصيات قابلة للتنفيذ.

## 📡 الدفعة الثالثة — اللوحة الحيّة + حالة النظام + النسخ الاحتياطي

### 6. Live Dashboard (`/admin/live`)
- استخدام Supabase Realtime (`presence` channels) لعرض:
  - المستخدمون المتصلون الآن، الطلاب داخل الامتحانات، داخل المحادثات.
  - عدّادات (الرسائل/الإشعارات/طلبات AI اليوم) تُحدَّث لحظياً.
- إضافة جدول `user_presence` + hook `usePresence`.

### 7. مراقبة حالة النظام (`/admin/system-status`)
- فحص لحظي لكل خدمة (DB, Storage, Auth, Realtime, FCM, AI, API, pg_cron).
- Server function `systemHealthCheck` تفحص كل خدمة وترجع الحالة + آخر نجاح + سبب الفشل.
- أيقونات ملوّنة 🟢🔴🟡 + زر إعادة اختبار.

### 8. النسخ الاحتياطي التلقائي (`/admin/backups`)
- جدول `backups` (النوع، الحجم، الحالة، تاريخ الإنشاء، المسار).
- server function `createBackup` تصدّر بيانات الجداول الأساسية كـ JSON إلى Storage bucket `backups`.
- pg_cron: نسخة يومية/أسبوعية/شهرية.
- واجهة: إنشاء يدوي، تنزيل، استعادة.

## 🎨 الدفعة الرابعة — API Architecture + التصميم العالمي

### 9. API Architecture (بنية جاهزة للتطبيقات)
- توثيق الـ server functions الموجودة كطبقة API نظيفة.
- إنشاء `src/routes/api/v1/*` للنقاط العامة (مع مصادقة Bearer token للتطبيقات المستقبلية).
- جدول `api_tokens` لإدارة مفاتيح التطبيقات.
- ملف `API.md` يوثّق كل نقطة.

### 10. تصميم احترافي عالمي
- تحديث `styles.css`: بالتيه ألوان مستوحاة من الخرائط القديمة والحضارات (كحلي عميق، ذهبي، تيراكوتا، أخضر زيتون داكن).
- إضافة Skeleton Loading لجميع القوائم.
- Animations خفيفة (framer-motion موجود).
- Glassmorphism بسيط في الـ Sidebar والـ Cards.
- تحسين Responsive وDark Mode.
- أيقونات موحّدة (Lucide).
