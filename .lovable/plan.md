
## نطاق التنفيذ

بناء على ما هو موجود بالفعل (تقارير أساسية، إعدادات AI، إدارة ملفات، إشعارات، gamification كامل)، سأركز على إضافة الطبقة الاحترافية النهائية دون تكرار أو تعديل الوظائف العاملة.

## 1) Dashboard احترافي (`/admin/dashboard` — إعادة بناء)
- بطاقات إحصائية حية: الطلاب (إجمالي/نشط/موقوف/متصل الآن)، الامتحانات (نشطة/مجدولة/منتهية، متوسط الدرجات، نسبة النجاح)، الرسائل (اليوم، غير مقروءة)، الجوائز (المستبدلة، النقاط الممنوحة)
- Charts: مخطط نشاط آخر 7 أيام، توزيع الدرجات، أعلى الطلاب نقاطًا
- قوائم سريعة: آخر الطلاب المسجلين، أكثر امتحان حلاً، آخر النشاطات
- لوحة AI مستقلة: عدد الطلبات، نجاح/فشل، متوسط الاستجابة، توزيع حسب المزود، آخر استخدام
- بحث عام في الهيدر (Command Palette) يبحث في الطلاب/الامتحانات/الرسائل/الجوائز/الملفات

## 2) صفحة التقارير المتقدمة (`/admin/reports` — توسيع)
تبويبات: الطلاب / الامتحانات / الرسائل / الجوائز / النشاط
- فلاتر مشتركة: الصف، المجموعة، الفترة الزمنية (from/to)، الحالة
- كل تقرير قابل للتصدير PDF/Excel مع رأس يحتوي شعار المنصة + التاريخ + اسم الأدمن + اسم التقرير
- تقارير جديدة: الحضور (من `activity_log` login events)، أصعب/أسهل الأسئلة (تحليل `attempt_answers`)، الرسائل والملفات المرسلة، الجوائز المستبدلة، سجل النقاط

## 3) سجل النشاط (`/admin/activity` — جديد)
- عرض جدولي من `activity_log` مع فلاتر (نوع العملية، المستخدم، الفترة)
- عرض IP والجهاز (user_agent مبسط)
- تصدير Excel
- ربط middleware تسجيل تلقائي لأهم العمليات (تسجيل دخول/خروج، تعديل امتحان، اعتماد نتيجة، إرسال إعلان...)

## 4) إعدادات المنصة (`/admin/settings` — إعادة بناء كاملة)
تبويبات:
- **الهوية**: اسم المنصة، الشعار (رفع)، أيقونة، ألوان أساسية، خطوط — مخزنة في جدول `settings`
- **الامتحانات**: زمن افتراضي، درجة نجاح، ترتيب الأسئلة، عدد المحاولات، مكافحة الغش
- **الرسائل**: حد حجم الملفات، أنواع مسموحة، مدة الاحتفاظ
- **الجوائز**: تفعيل النقاط/الشارات/المستويات/المتجر
- **الأمان**: مدة الجلسة، الحد الأقصى لمحاولات الدخول، تغيير كلمة مرور الأدمن
- **النسخ الاحتياطي**: زر تصدير JSON لكامل البيانات (تنزيل)، عرض معلومات آخر نسخة

## 5) إدارة الملفات المتقدمة (`/admin/files` — توسيع)
- بحث، فلترة حسب النوع والحجم، إعادة تسمية، عدد التحميلات (عمود جديد)، معاينة سريعة

## 6) قاعدة البيانات — Migration واحد
- إضافة أعمدة `settings` مطلوبة (كل الإعدادات في صفوف key/value)
- Trigger لتسجيل تسجيل دخول الطلاب/الأدمن في `activity_log`
- View لتجميع إحصائيات Dashboard (اختياري لتحسين الأداء)
- Indexes على الأعمدة الأكثر استعلامًا (`points_log.student_id`, `activity_log.created_at DESC`, `messages.created_at`)

## 7) PWA وتحسينات
- التحقق من `manifest.webmanifest` (موجود) — إضافة `screenshots` array
- Lazy loading للـ routes الثقيلة (`admin.reports`, `admin.ai`, `admin.competitions`) عبر dynamic import
- Pagination في الجداول الكبيرة (سجل النشاط، الرسائل)

## 8) واتساب في كل مكان
- التأكد من ظهور زر WhatsApp في: بطاقة الطالب، النتائج، الرسائل، Dashboard مع quick-actions

## المخرجات
حوالي 8-10 ملفات جديدة/معدلة + migration واحد. لن ألمس: `students.functions.ts`, `exams.functions.ts`, `gamification.ts`, `messaging.functions.ts`, أو أي مكون يعمل حاليًا.
